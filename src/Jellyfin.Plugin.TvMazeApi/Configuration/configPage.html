Metadata

Cast, creators and producers for series; guest stars, directors and writers for episodes. Jellyfin takes people from the first metadata provider that has any. Turn this off, or put TVmaze API below TheMovieDb in your library settings, if you want people from another provider.

Rate limit

TVmaze allows at least 20 calls per 10 seconds per IP address.

TVmaze account

Optional. Link a Jellyfin user to a TVmaze account to mark watched episodes on TVmaze. Metadata does not need an account. Your API key is on your TVmaze dashboard.
Episodes you finish or mark as played in Jellyfin are marked as watched on TVmaze. To send your existing history, run Sync watched episodes to TVmaze under Scheduled Tasks.
